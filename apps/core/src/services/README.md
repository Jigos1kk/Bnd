# services

Бизнес-логика: правила приложения, которые не относятся напрямую ни к сокетам, ни к БД.

Сервис принимает данные, применяет логику и работает с `repositories`.

Пример: `messageService.ts`

```ts
export const messageService = {
  send: async (userId: string, text: string) => {
    // валидация, сохранение через repository, возврат результата
  },
};
```

Обработчики сокетов вызывают сервисы, а не репозитории напрямую.
