# handlers

Обработчики событий Socket.IO. Один файл — одна группа событий (например `chat.ts`, `game.ts`).

Каждый обработчик — функция, которая принимает `socket` (и при необходимости `io` / `db`)
и регистрирует `socket.on(...)`.

Данные берутся через `repositories` / `services`, а не напрямую из БД.
