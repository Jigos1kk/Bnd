# socket

Всё, что связано с Socket.IO.

- `SocketServer.ts` — класс сервера: создание HTTP + Socket.IO, подключения, старт/остановка.
- `events.ts` — константы имён событий (единый источник правды для сервера и клиента).
- `handlers/` — обработчики событий подключения.
- `middleware/` — middleware для сокетов (auth и др.).
