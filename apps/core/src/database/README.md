# database

Всё, что связано с базой данных.

- `Database.ts` — класс подключения к MongoDB (connect / disconnect / статус).
- `models/` — Mongoose-схемы и модели. Одна модель — один файл (например `User.ts`, `Message.ts`).
- `repositories/` — слой доступа к данным: функции поверх моделей (поиск, создание, обновление).
  Обработчики сокетов и сервисы не работают с Mongoose напрямую — только через репозитории.
